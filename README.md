# 윈세프 발주서 자동 확인 봇

평일 09:00~16:00(한국시간)에 **10분마다** 네이버 메일의 `발주서` 메일함을 확인합니다.
새 발주서가 오면 첨부 엑셀을 **윈세프 발주서 "일반 주문건" 양식으로 변환**합니다.
변환한 파일은 **내 메일로 보내고**, 현황판 웹페이지에 도착 현황을 표시합니다.

```
네이버 '발주서' 메일함 ──(10분마다, GitHub Actions)──> 변환 프로그램(Node.js)
                                                     ├─> 변환 엑셀을 내 메일로 발송 (고객정보는 여기만)
                                                     └─> docs/status.json ─> 현황판 (GitHub Pages)
```

참고한 사이트(체험단 앱)와 같은 구조입니다. 무료 범위(GitHub Actions + GitHub Pages) 안에서 돌아갑니다.

## 처음 한 번만 하는 설정 (약 20분)

### 1단계. 네이버 메일 준비
1. 네이버 메일 → **환경설정 → POP3/IMAP 설정 → `IMAP/SMTP 설정` 탭** → **사용함** → 저장
2. 네이버 **2단계 인증**을 켭니다. (내정보 → 보안설정)
3. 같은 곳에서 **애플리케이션 비밀번호**를 만듭니다. 종류는 "기타", 이름은 `발주봇`처럼 정하면 됩니다.
   - 화면에 나온 비밀번호를 메모해 두세요. 이 비밀번호는 **4단계에서 GitHub에만** 넣고, 채팅이나 메일에는 적지 마세요.
4. 보안설정에 **해외 로그인 차단**이 켜져 있다면 끄거나 예외를 확인하세요. GitHub 서버가 해외에 있어서 차단될 수 있습니다.

### 2단계. GitHub 저장소 만들기
1. https://github.com 에 가입하고 로그인합니다.
2. 오른쪽 위 **+ → New repository**
   - Repository name: `winchef-order-bot`
   - **Public**을 고릅니다. 무료 계정에서 현황판(GitHub Pages)을 쓰려면 공개여야 합니다.
     공개라도 고객 이름·연락처·주소는 저장소에 **절대 올라가지 않도록** 만들어 두었습니다. 다만 거래처 이름과 메일 제목은 보입니다.
     이게 싫다면 **Private**으로 만들고 5단계(현황판)를 건너뛰세요. 그래도 메일 발송은 됩니다.
3. **Create repository**

### 3단계. 파일 올리기
1. 받은 `winchef-order-bot.zip`의 압축을 풉니다.
2. 저장소 화면의 **uploading an existing file** 링크를 누릅니다.
3. 압축을 푼 폴더 **안의 내용 전체**(`src`, `docs`, `test`, `.github`, `package.json`, `package-lock.json`, `README.md`)를 끌어다 놓고 **Commit changes**를 누릅니다.
   - ⚠️ `.github` 폴더는 숨김 폴더라 안 보일 수 있습니다. (맥: Finder에서 `Cmd + Shift + .`, 윈도우: 탐색기 보기 → 숨긴 항목)
   - 그래도 안 올라가면 **Add file → Create new file**을 누르고, 파일 이름 칸에 `.github/workflows/check-orders.yml`을 입력한 뒤 같은 이름 파일의 내용을 붙여 넣고 저장하세요.

### 4단계. 비밀값 넣기 (네이버 로그인 정보)
저장소 **Settings → Secrets and variables → Actions → New repository secret**에서 아래를 하나씩 추가합니다.

| Name | Secret (값) |
|---|---|
| `NAVER_ID` | 네이버 아이디 (`@naver.com` 빼고) |
| `NAVER_APP_PASSWORD` | 1단계에서 만든 **애플리케이션 비밀번호** |
| `MAIL_TO` | (선택) 변환 파일을 받을 메일 주소. 없으면 네이버 메일로 보냅니다 |

비밀값은 넣은 뒤에는 누구도(본인 포함) 다시 볼 수 없고, 실행할 때만 쓰입니다.

그다음 **Settings → Actions → General → Workflow permissions → Read and write permissions** 선택 → Save.

### 5단계. 현황판 켜기 (선택)
**Settings → Pages → Build and deployment**
- Source: **Deploy from a branch**
- Branch: **main**, 폴더 **/docs** → Save

1~2분 뒤 `https://(GitHub아이디).github.io/winchef-order-bot/` 에서 현황판이 열립니다. 휴대폰에서도 볼 수 있습니다.

### 6단계. 첫 실행
1. 저장소 **Actions** 탭 → 왼쪽 **발주서 메일 확인** → **Run workflow**
2. 1~2분 뒤 초록색 ✅이면 성공입니다. 빨간색 ❌이면 눌러서 `메일 확인·변환` 단계의 메시지를 확인하세요.

| 메시지 | 해결 |
|---|---|
| `NAVER_ID … 비밀값이 없습니다` | 4단계 이름 철자 확인 |
| `Authentication failed` / 로그인 실패 | 애플리케이션 비밀번호 다시 만들기, IMAP 사용함 확인, 해외 로그인 차단 확인 |
| `'발주서' 메일함을 찾지 못했습니다` | 메시지에 나온 메일함 목록을 보고 `src/vendors.json`의 `"메일함"` 이름 수정 |
| `Permission denied` (현황판 저장 단계) | 4단계 Workflow permissions 확인 |

이후에는 평일 업무시간에 알아서 돕니다.

## 매일 쓰는 법
1. 거래처 발주 메일이 오면 10~20분 안에 **`[발주 자동변환] 거래처 N줄 (1차/2차)`** 메일이 옵니다.
2. 첨부 엑셀의 줄을 복사해서 발주서 **일반 주문건 벤더 구역**에 붙여 넣습니다.
   - 마지막 열 **"확인 필요"**에 글이 있는 줄(노란 칸)은 직접 확인하고 고친 뒤, 이 열은 지우고 붙여 넣으세요.
   - 10:30 이후~13:30 전에 도착한 메일은 **2차**로 표시되고, P열이 보라색으로 칠해져 있습니다.
3. 현황판에서 **아직 안 온 거래처**를 한눈에 봅니다. 10:30이 지나도 매일 오는 거래처가 안 오면 노란색으로 표시됩니다.

## 변환 규칙 (윈세프 발주서 작성규칙 기준)
- 머리글 이름으로 열을 찾습니다: 발주처·유형·색상(→옵션)·모델명·수량·고객명·전화번호 1/2·배송처(→주소)·비고·배송메세지
- 모델명 칸에 상품명이 통째로 와도 모델 글자를 찾아 **매뉴얼 표기**로 바꿉니다. (예: `…(WTK-2113CG)1L/…` → `1L / 차콜그레이 / WTK-2113(CG)`)
- 같은 모델에 R/L, 색상 후보가 여러 개면 힌지 글자(우힌지·좌측열림 → R 등)와 색상으로 고르고, 그래도 모르면 **비우지 않고 "확인 필요"로 표시**합니다.
- 색상 `없음` → 빈칸, 연락처는 텍스트(맨 앞 0 유지), 연락처 2가 연락처 1과 같으면 빈칸
- 발주처 별칭: 위드무케 → `선물하기`, WHITEGOODS → `㈜화이트굿즈코퍼레이션`, ERI → `이알아이`
- 메일은 **읽음 표시를 바꾸지 않습니다.** 네이버 메일함은 지금처럼 그대로 쓰시면 됩니다.

## 고칠 수 있는 곳
| 파일 | 내용 |
|---|---|
| `src/vendors.json` | 거래처 목록, 보낸 사람 글자, 매일 오는 거래처 여부, 메일함 이름 |
| `src/models.json` | 모델 표기표. 지금은 이니스리테일 발주서에 붙어 온 `발주용 모델리스트` + 규칙서 확정 표기입니다. **최신 `발주서 모델 표기 매뉴얼`로 바꾸는 게 좋습니다.** (Claude에게 매뉴얼 파일을 주면 이 파일을 다시 만들어 줍니다) |
| `.github/workflows/check-orders.yml` | 실행 시간 (`*/10 0-6 * * 1-5` = 평일 09~15시대 10분마다, UTC 기준) |

## 알아 둘 한계
- GitHub의 예약 실행은 **5~15분, 바쁠 때는 더 늦게** 시작될 수 있습니다. 10:30 마감 직전에 온 메일은 직접 확인하는 게 안전합니다.
- 평일이면 공휴일에도 돕니다. (메일이 없으면 아무 일도 안 합니다)
- `.xlsx`만 변환합니다. 예전 형식 `.xls`나 PDF는 현황판에 "변환 불가"로 표시됩니다.
- 처음 보는 거래처 양식은 열을 못 찾을 수 있습니다. 그런 파일은 Claude에게 보여 주면 규칙을 추가합니다.
- 사방넷·쇼핑몰 주문, 교환·반품·회수, 사은품·다이어리 이벤트는 이 봇이 다루지 않습니다. (B2B 거래처 발주서 전용)
- 현황판은 저장소가 공개면 주소를 아는 누구나 볼 수 있습니다. (검색엔진 노출은 막아 두었습니다)
